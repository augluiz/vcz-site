Execute o script de atualização para baixar os indicadores de preços do CEPEA antes de abrir o dashboard.

1. Acesse a pasta do projeto:

cd C:\Users\augus\vcz-site\cepea_dashboard

2. Instale dependências (primeira vez):

pip install requests beautifulsoup4 lxml

3. Baixe os dados:

python atualizar.py

4. Sirva localmente e abra no browser:

cd ..\ python -m http.server 8080 # abra: http://localhost:8080/cepea_dashboard/
